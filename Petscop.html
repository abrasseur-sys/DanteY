Petscop


Brief History


Petscop is a game that was meant to release in 1997 for the PSX by a company named Garalina, which has published no other title.

It is a puzzle-exploration game where the main character, the guardian, must go catch all pets found inside Even Care.
The premise unfolds as you start on the Gift Plane, which would serve as the main hub if the game was in a state of completion.


However, it is not.

This is because Even Care is the only level that has been finished, or atleast it seems that way on the surface.
