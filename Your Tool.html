Various Tools can be found in-game, which vary in different colors and uses.



Your Tool


Tools are objects dispersed all across the Newmaker Plane that one can find and interact with.


A red Tool can be found in the same room where one can view the windmill. When used, it shows up an interface for entering questions, which it then responds to. Below is a compilation of all of the known question that have yielded answers:

- Newmaker
"Where am i?"
- Under the Newmaker Plane
"Who are you?"

- I'm not

A green Tool accompanies the player in the school. It functions the same way a cursor would do, letting you be able to interact with things in first person.

There's 2 instances of a blue Tool,
One can be found in the same room as the red Tool in the form of drawings, seemingly made with crayon.

The other one is found in the road outside the house, moving away from the player if tried to be reached, untill cornered, at which it starts levitating. The bucket found in the house has to be brought to the spot where it starts floating, one must move away so the Tool gets trapped inside it. Once the tool is brought to the house the player can get 15 pieces from the object on the table.
